@chamvi/github ​

The GitHub channel (webhook deliveries in, issue comments out) and GitHub tools for chamvi agents. The public API of packages/github/src/index.ts.

bash
npm install @chamvi/github @chamvi/http @chamvi/core ai --save

@chamvi/core, @chamvi/http and ai are peer dependencies. See GitHub App for setup and behaviour.

createGithubApp ​

ts
function createGithubApp(options: GithubAppOptions): IGithubApp;

const DEFAULT_GITHUB_API_URL: 'https://api.github.com';
const INSTALLATION_CACHE_TTL_MS: 600_000;

Throws InvalidAgentDefinitionError for an empty appId, a key that is no RSA private key, an empty webhook secret, an installationId that is no positive integer, a baseUrl that is no absolute https URL without query (empty means https://api.github.com) and a slug that is not the App's lower-case slug (^[a-z0-9]+(-[a-z0-9]+)*$, as in the App's URL; a miscased one would silently disable the self guard).

import type { ToolSet } from 'ai';
import type { IClock } from '@chamvi/core';
import type { PaginatedOctokit } from './helpers.ts';

export type GithubAppOptions = {
    appId: string | number;
    /** PEM (PKCS#1 or PKCS#8); literal "\n" sequences become newlines. */
    privateKey: string;
    /** Several during a secret rotation; a delivery verifies under any. */
    webhookSecret: string | readonly string[];
    /** For runs not started by a delivery (cron, http, mcp) and comments on their behalf. */
    installationId?: number;
    /** The App's slug; skips `GET /app` for the bot login. */
    slug?: string;
    /** Default DEFAULT_GITHUB_API_URL ('https://api.github.com'). */
    baseUrl?: string;
    clock?: IClock;
    fetch?: typeof globalThis.fetch;
};

/** An Octokit (`@octokit/core` with `paginate`). */
export type GithubOctokit = InstanceType<typeof PaginatedOctokit>;

/** GitHub App permissions of a token, e.g. `{ contents: 'write', workflows: 'write' }`. */
export type GithubPermissions = Record<string, 'read' | 'write'>;

/** A short-lived token of one repository (`IGithubApp.repositoryToken`). */
export type GithubRepositoryToken = {
    token: string;
    expiresAt: Date;
};

/** The App's bot as a git commit identity. */
export type GithubBotIdentity = {
    /** `<slug>[bot]`. */
    name: string;
    /** `<bot user id>+<slug>[bot]@users.noreply.github.com`, which GitHub links to the bot. */
    email: string;
};

/** An installation of the App (`IGithubApp.installations()`). */
export type GithubInstallation = {
    id: number;
    /** The account login, e.g. `tada5hi` or an org. */
    account: string;
    /** `User` or `Organization`. */
    accountType: string;
    repositorySelection: 'all' | 'selected';
    permissions: GithubPermissions;
    /** Whether the account suspended the App (`suspended_at` set): its token exchange answers 403. */
    suspended: boolean;
};

/** A merge method of `github_merge_pull_request`. */
export type GithubMergeMethod = 'merge' | 'squash' | 'rebase';

/** Options of `IGithubApp.writeTools()`. */
export type GithubWriteToolsOptions = {
    /** The merge method when a call names none (default DEFAULT_MERGE_METHOD, `squash`). */

export interface IGithubApp {
    readonly appId: string;
    readonly installationId?: number;
    /** An Octokit authenticated as the installation (cached token). */
    octokit(installationId: number): Promise<GithubOctokit>;
    /** `<slug>[bot]`, from `slug` or one `GET /app`; cached, single-flight. */
    botLogin(): Promise<string>;
    /**
     * The bot as a commit identity (`GET /users/<login>` for its user id,
     * once; a failure is not cached), e.g. the workspace manager's `author`.
     */
    botIdentity(): Promise<GithubBotIdentity>;
    /**
     * A token limited to one repository and `permissions` (the deferred
     * scoped token of plan 014): the App's installation on the repository
     * (`GET /repos/{owner}/{repo}/installation`), then an exchange with
     * `repositories: [repo]`. Cached per repository and permissions until 5
     * minutes before it expires, concurrent callers share one exchange, a
     * failure is not cached. Undefined when the App is not installed there.
     */
    repositoryToken(target: { owner: string; repo: string }, options: { permissions: GithubPermissions }): Promise<GithubRepositoryToken | undefined>;
    /**
     * The App's installation on the repository (App JWT `GET
     * /repos/{owner}/{repo}/installation`), cached per lower-cased
     * `owner/repo` for INSTALLATION_CACHE_TTL_MS on the clock; concurrent
     * callers share one lookup. Undefined (not cached) when the App is not
     * installed there; a failure is a `github_request` ChamviError and not
     * cached.
     */
    installationFor(target: { owner: string; repo: string }): Promise<number | undefined>;
    /**
     * The whole installation `installationFor()` looked up (account,
     * permissions), from the same cache; undefined where the App is not
     * installed.
     */
    repositoryInstallation(target: { owner: string; repo: string }): Promise<GithubInstallation | undefined>;
    /** Every installation of the App (`GET /app/installations`, paginated), not cached. */
    installations(): Promise<GithubInstallation[]>;
    /** `sha256=<hex>` of the raw body under any webhook secret, compared in constant time. */
    verifySignature(body: Uint8Array, signature: string | null): boolean;
    /**
     * The read-only tools (`github_get_issue`, `github_search_issues`,
     * `github_list_pull_requests`, ...), each acting as the installation of
     * the repository it names.
     */
    readTools(): ToolSet;
    /**
     * The write tools (`github_add_labels`, `github_create_comment`,
     * `github_close_issue`, `github_create_issue`,
     * `github_create_pull_request`, `github_merge_pull_request`), effect
     * tools applied at most once per run. An unknown `mergeMethod` is an
     * InvalidAgentDefinitionError.
     */
    writeTools(options?: GithubWriteToolsOptions): ToolSet;
}

installationFor({ owner, repo }) answers the App's installation on a repository (App JWT, cached per lower-cased owner/repo for INSTALLATION_CACHE_TTL_MS on the clock, concurrent callers sharing one lookup; undefined, not cached, where the App is not installed); repositoryInstallation({ owner, repo }) answers the whole installation of that lookup (GithubInstallation, permissions included) from the same cache; installations() lists every installation (GET /app/installations, not cached). writeTools({ mergeMethod }) throws InvalidAgentDefinitionError for a method outside MERGE_METHODS.

ts
const GITHUB_REQUEST_ERROR_CODE: 'github_request';
const REPO_PATTERN: string; // '^([\\w.-]*[\\w-][\\w.-]*)/([\\w.-]*[\\w-][\\w.-]*)$'

GITHUB_REQUEST_ERROR_CODE is the code of every failed GitHub request (the tools' errors and the channel's send failures); REPO_PATTERN is the owner/name rule the tools apply (GitHub's name characters, each segment with one that is not a dot, so . and .. never fold the URL into another API path). Build a RegExp from it.

Every option is checked when githubChannel() is called (InvalidAgentDefinitionError). Register the channel on the engine and list it in createHttpApp({ channels }), which serves its in at POST /channels/<name> (the deliveries: signature, self guard, one run per matching agent, 202 with a GithubWebhookResult). Its out(message, address) comments on the issue or pull request address names (owner/repo#n, else a ValidationError), deduplicated by the marker effectMarker(message.key). An approval with options lists them fenced as - <id>: <label> under Options (choose one): (or Options (choose one or more):), the body is cut by that block's length, and the link line reads Choose and approve or deny: <link>. See GitHub App for both directions.

github.on, github.to ​

ts
const github: GithubSubscriber; // github.on(events, options?), github.to({ repo, number }) for the channel named 'github'

github.on() throws InvalidAgentDefinitionError without events or for an event that is not name or name.action (lower case letters, digits and underscores, e.g. projects_v2_item.created), and for a selfEvents entry of that shape naming issue_comment, issues or pull_request_review_comment (the bot's own comment would start the agent again). A bot-sent delivery starts each agent's first matching subscription whose selfEvents name it; a bare pull_request there also takes the labeled, closed and synchronize deliveries the agent's own tools and pushes cause, so name the actions (pull_request.opened). A delivery the App's bot sent reaches only subscriptions whose selfEvents name its event. github.to({ repo, number }) returns the address <owner>/<repo>#<number>.

/*
 * Copyright (c) 2026.
 * Author Peter Placzek (tada5hi)
 * For the full copyright and license information,
 * view the LICENSE file that was distributed with this source code.
 */

import type { ChannelSubscription } from '@chamvi/core';

/** The parts of a GitHub webhook body chamvi reads; the rest passes through. */
export type GithubPayload = {
    action?: string;
    installation?: { id: number };
    repository?: { full_name: string; [key: string]: unknown };
    sender?: {
        login: string;
        type: string;
        [key: string]: unknown
    };
    issue?: { number: number; [key: string]: unknown };
    pull_request?: { number: number; [key: string]: unknown };
    [key: string]: unknown;
};

/** The envelope payload of a run the GitHub channel started. */
export type GithubEvent = {
    /** X-GitHub-Event, e.g. 'issues'; not covered by the signature, so never a key on its own. */
    name: string;
    action?: string;
    /** X-GitHub-Delivery; not covered by the signature. */
    delivery: string;
    installationId?: number;
    payload: GithubPayload;
};

export type GithubSubscriptionOptions = {
    /** Shared-store execution cap within the agent; omitted or false adds no cap. */
    concurrencyMaxRuns?: number | false;
    /** Default `github:<events joined by ','>`. */
    id?: string;
    /** Runs after the event match; a delivery it refuses starts no run of this subscription. */
    filter?: (event: GithubEvent) => boolean;
    /**
     * Default: the delivery id (applied by the channel). The signature does not
     * cover that header, so a replayed body under a new id is a new run;
     * derive the key from the content on an exposed endpoint.
     */
    idempotencyKey?: (event: GithubEvent) => string | undefined;
    /** Default: `<full_name>#<issue|pull_request number>`, else `<full_name>`. */
    concurrencyKey?: (event: GithubEvent) => string | undefined;
    /**
     * Events (`name` or `name.action`) the App's own bot may start this
     * subscription with, e.g. `['pull_request.opened',
     * 'pull_request.synchronize', 'check_suite.completed']` for the pull
     * requests the agent opens or pushes to. Every other delivery the bot
     * sent dispatches nothing (the loop guard). A bare `pull_request` also
     * takes the `labeled`, `closed`, ... the agent's own tools cause, so it
     * starts again after each of its writes: name the actions. The agent's
     * first subscription matching the event whose `selfEvents` name it is
     * the one started.
     * `issue_comment`, `issues` and `pull_request_review_comment` are
     * refused (InvalidAgentDefinitionError): the bot's own comment would
     * start the agent again.
     */
    selfEvents?: readonly string[];
};

/** An issue or pull request, for `github.to()`. */
export type GithubTarget = {
    /** `owner/name`. */
    repo: string;
    /** The issue or pull request number. */
    number: number;
};

/** Makes GitHub subscriptions and addresses for one channel name. */
export type GithubSubscriber = {
    /**
     * A subscription to deliveries of `events`: `'issues'` (every action) or
     * `'issues.opened'`, one or several.
     */
    on(events: string | readonly string[], options?: GithubSubscriptionOptions): ChannelSubscription<GithubEvent>;
    /** The address of an issue or pull request, `<owner>/<repo>#<number>`. */
    to(target: GithubTarget): string;
};

Tools ​

ts
const DEFAULT_MERGE_METHOD: 'squash';
const MERGE_METHODS: readonly ['merge', 'squash', 'rebase'];

gh.readTools() (github_get_issue, github_search_issues, github_list_labels, github_get_pull_request, github_get_file, github_get_latest_release, github_list_releases, github_compare, github_list_repositories, github_list_issues, github_list_pull_requests, github_get_pull_request_checks, github_get_push_target) and gh.writeTools(options?) (github_add_labels, github_create_comment, github_close_issue, github_create_issue, github_create_pull_request, github_merge_pull_request) return plain AI SDK ToolSets. Each tool acts as the installation of the repository it names: the delivery's for a run of the GitHub channel on that repository, else installationFor(), else the delivery's or installationId (a public repository the App is not installed on stays readable); without any a github_request tool error. github_merge_pull_request refuses with ToolDeniedError, before the merge request, a closed pull request, a head that moved from sha, a draft, a mergeability not computed yet, a mergeable_state outside MERGE_STATES any required check that is not green or has not reported, required checks it cannot read (a 403 or 404 on the branch or its rules, required.known false), a head without any check yet and any check still running; a failing check that is not required does not stop it. The results are these shapes.

Git credentials ​

ts
function githubAppCredentials(app: IGithubApp, options?: GithubAppCredentialsOptions): IGithubGitCredentials;

const DEFAULT_GITHUB_GIT_HOST: 'github.com';
const GITHUB_TOKEN_USERNAME: 'x-access-token';

The workspace manager's credentials source for the App (typed structurally against @chamvi/sandbox's IGitCredentials, which this package does not depend on): for a request of its host (default github.com) and an owner/name path it answers app.repositoryToken() as x-access-token, with contents: read for read and contents: write plus options.permissions for write; nothing for another host, the host itself or a repository the App is not installed on, so the next source (or an anonymous call) follows. Throws InvalidAgentDefinitionError for an app without repositoryToken, permissions that are not read or write and a host that is no host name. app.repositoryToken({ owner, repo }, { permissions }) finds the installation (GET /repos/{owner}/{repo}/installation, a 404 answers undefined) and exchanges a token with repositories: [repo], cached per installation, repository and permissions until 5 minutes before it expires (one exchange for concurrent callers, failures not cached); app.botIdentity() is { name: '<slug>[bot]', email: '<user id>+<slug>[bot]@users.noreply.github.com' } (one public GET /users/<login>), for the manager's author.

    /** `owner/name`; empty for the host itself. */
    path: string;
    access: 'read' | 'write';
    runId: string;
    signal?: AbortSignal;
};

githubModule() provides its app; with a hand-built engine call provideGithubContext(engine, gh) after new Engine(). Inject in a tools factory (tools: (ctx) => injectGithubContext(ctx).readTools()), in a tool's execute or in an effect hook; see Context. One app per engine: a second provide throws InvalidAgentDefinitionError.

Module ​

ts
// @chamvi/github/module, needs @chamvi/app
function githubModule(options?: GithubModuleOptions): GithubModule; // name GITHUB_MODULE_NAME 'chamvi:github', .app: IGithubApp

Reads GITHUB_APP_ID, GITHUB_APP_PRIVATE_KEY, GITHUB_WEBHOOK_SECRET (comma-separated), GITHUB_INSTALLATION_ID, GITHUB_APP_SLUG and GITHUB_API_URL from options.env ?? process.env when it is called, unless options.app is given; explicit options win. setup contributes githubChannel() (options.channel, the approval link from CHAMVI_PUBLIC_URL unless channel.approvalUrl is given, the app's clock) to the app's channels, which the http module serves at /channels/<name>, and githubAppCredentials(app, options.credentials) to AppToken.GIT_CREDENTIALS, which sandboxModule() asks after its own sources (credentials: false contributes none), and the engineCreated hook provides .app. @chamvi/app is an optional peer: the main entry never imports it. See Apps & Modules.
