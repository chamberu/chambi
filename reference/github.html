@chamvi/github ​

The GitHub channel (webhook deliveries in, issue comments out) and GitHub tools for chamvi agents. The public API of packages/github/src/index.ts.

bash
npm install @chamvi/github @chamvi/http @chamvi/core ai --save

@chamvi/core, @chamvi/http and ai are peer dependencies. See GitHub App for setup and behaviour.

createGithubApp ​

ts
function createGithubApp(options: GithubAppOptions): IGithubApp;

const DEFAULT_GITHUB_API_URL: 'https://api.github.com';

Throws InvalidAgentDefinitionError for an empty appId, a key that is no RSA private key, an empty webhook secret, an installationId that is no positive integer, a baseUrl that is no absolute https URL without query (empty means https://api.github.com) and a slug that is not the App's lower-case slug (^[a-z0-9]+(-[a-z0-9]+)*$, as in the App's URL; a miscased one would silently disable the self guard).

ts
/*
 * Copyright (c) 2026.
 * Author Peter Placzek (tada5hi)
 * For the full copyright and license information,
 * view the LICENSE file that was distributed with this source code.
 */

import type { ToolSet } from 'ai';
import type { IClock } from '@chamvi/core';
import type { PaginatedOctokit } from './helpers.ts';

export type GithubAppOptions = {
    appId: string | number;
    /** PEM (PKCS#1 or PKCS#8); literal "\n" sequences become newlines. */
    privateKey: string;
    /** Several during a secret rotation; a delivery verifies under any. */
    webhookSecret: string | readonly string[];
    /** For runs not started by a delivery (cron, http, mcp) and comments on their behalf. */
    installationId?: number;
    /** The App's slug; skips `GET /app` for the bot login. */
    slug?: string;
    /** Default DEFAULT_GITHUB_API_URL ('https://api.github.com'). */
    baseUrl?: string;
    clock?: IClock;
    fetch?: typeof globalThis.fetch;
};

/** An Octokit (`@octokit/core` with `paginate`). */
export type GithubOctokit = InstanceType<typeof PaginatedOctokit>;

export interface IGithubApp {
    readonly appId: string;
    readonly installationId?: number;
    /** An Octokit authenticated as the installation (cached token). */
    octokit(installationId: number): Promise<GithubOctokit>;
    /** `<slug>[bot]`, from `slug` or one `GET /app`; cached, single-flight. */
    botLogin(): Promise<string>;
    /** `sha256=<hex>` of the raw body under any webhook secret, compared in constant time. */
    verifySignature(body: Uint8Array, signature: string | null): boolean;
    /** The read-only tools (`github_get_issue`, `github_search_issues`, ...), acting as the run's installation. */
    readTools(): ToolSet;
    /**
     * The write tools (`github_add_labels`, `github_create_comment`,
     * `github_close_issue`), effect tools applied at most once per run.
     */
    writeTools(): ToolSet;
}
ts
const GITHUB_REQUEST_ERROR_CODE: 'github_request';
const REPO_PATTERN: string; // '^([\\w.-]*[\\w-][\\w.-]*)/([\\w.-]*[\\w-][\\w.-]*)$'

GITHUB_REQUEST_ERROR_CODE is the code of every failed GitHub request (the tools' errors and the channel's send failures); REPO_PATTERN is the owner/name rule the tools apply (GitHub's name characters, each segment with one that is not a dot, so . and .. never fold the URL into another API path). Build a RegExp from it.

githubChannel ​

ts
function githubChannel(options: GithubChannelOptions): GithubChannel; // IChannel with in and out, plus on() and to() bound to its name

const GITHUB_CHANNEL_NAME: 'github';
const GITHUB_CHANNEL_TIMEOUT_MS: 30_000;
const COMMENT_BODY_MAX_LENGTH: 60_000;
ts
/** What `approvalUrl` gets: ids only, never a token. */
export type GithubApprovalRef = {
    runId: string;
    approvalId: string;
    agent: string;
};

export type GithubChannelOptions = {
    app: IGithubApp;
    /** The channel name; default `'github'`. A second instance needs its own. */
    name?: string;
    /** Logins mentioned at the top of every comment (without `@`). */
    mention?: string | readonly string[];
    /**
     * A link to the approval in the chamvi UI, e.g.
     * `https://<app>/ui/approvals?run=<runId>&approval=<approvalId>`, where the
     * signed-in owner answers it; it carries no token.
     */
    approvalUrl?: (ref: GithubApprovalRef) => string;
    /** Bound of one comment send; default `GITHUB_CHANNEL_TIMEOUT_MS` (30 s). */
    timeoutMs?: number;
    /** Bytes a delivery may have (413 above); default 1 MiB. */
    bodyLimit?: number;
    /**
     * Receives each agent a delivery could not be dispatched to (a throwing
     * filter or key function, a refused key, a failed dispatch); the delivery
     * is then answered 500. Default `console.error('[chamvi]', error)`.
     */
    onError?: (error: unknown) => void;
    clock?: IClock;
};

/** The GitHub channel: deliveries `in`, issue and pull request comments `out`, with `on()` and `to()` bound to its name. */
export type GithubChannel = IChannel<ChannelRequest, Response> & GithubSubscriber;

Every option is checked when githubChannel() is called (InvalidAgentDefinitionError). Register the channel on the engine and list it in createHttpApp({ channels }), which serves its in at POST /channels/<name> (the deliveries: signature, self guard, one run per matching agent, 202 with a GithubWebhookResult). Its out(message, address) comments on the issue or pull request address names (owner/repo#n, else a ValidationError), deduplicated by the marker effectMarker(message.key). See GitHub App for both directions.

ts
/*
 * Copyright (c) 2026.
 * Author Peter Placzek (tada5hi)
 * For the full copyright and license information,
 * view the LICENSE file that was distributed with this source code.
 */

/** The `202` answer to a delivery: the run each matching agent got (deduplicated on a redelivery). */
export type GithubWebhookResult = {
    delivery: string;
    runs: Array<{
        agent: string;
        runId: string;
        deduplicated: boolean;
    }>;
};

github.on, github.to ​

ts
const github: GithubSubscriber; // github.on(events, options?), github.to({ repo, number }) for the channel named 'github'

github.on() throws InvalidAgentDefinitionError without events or for an event that is not name or name.action (lower case letters, digits and underscores, e.g. projects_v2_item.created). github.to({ repo, number }) returns the address <owner>/<repo>#<number>.

ts
/*
 * Copyright (c) 2026.
 * Author Peter Placzek (tada5hi)
 * For the full copyright and license information,
 * view the LICENSE file that was distributed with this source code.
 */

import type { ChannelSubscription } from '@chamvi/core';

/** The parts of a GitHub webhook body chamvi reads; the rest passes through. */
export type GithubPayload = {
    action?: string;
    installation?: { id: number };
    repository?: { full_name: string; [key: string]: unknown };
    sender?: {
        login: string;
        type: string;
        [key: string]: unknown
    };
    issue?: { number: number; [key: string]: unknown };
    pull_request?: { number: number; [key: string]: unknown };
    [key: string]: unknown;
};

/** The envelope payload of a run the GitHub channel started. */
export type GithubEvent = {
    /** X-GitHub-Event, e.g. 'issues'; not covered by the signature, so never a key on its own. */
    name: string;
    action?: string;
    /** X-GitHub-Delivery; not covered by the signature. */
    delivery: string;
    installationId?: number;
    payload: GithubPayload;
};

export type GithubSubscriptionOptions = {
    /** Default `github:<events joined by ','>`. */
    id?: string;
    /** Runs after the event match; a delivery it refuses starts no run of this subscription. */
    filter?: (event: GithubEvent) => boolean;
    /**
     * Default: the delivery id (applied by the channel). The signature does not
     * cover that header, so a replayed body under a new id is a new run;
     * derive the key from the content on an exposed endpoint.
     */
    idempotencyKey?: (event: GithubEvent) => string | undefined;
    /** Default: `<full_name>#<issue|pull_request number>`, else `<full_name>`. */
    concurrencyKey?: (event: GithubEvent) => string | undefined;
};

/** An issue or pull request, for `github.to()`. */
export type GithubTarget = {
    /** `owner/name`. */
    repo: string;
    /** The issue or pull request number. */
    number: number;
};

/** Makes GitHub subscriptions and addresses for one channel name. */
export type GithubSubscriber = {
    /**
     * A subscription to deliveries of `events`: `'issues'` (every action) or
     * `'issues.opened'`, one or several.
     */
    on(events: string | readonly string[], options?: GithubSubscriptionOptions): ChannelSubscription<GithubEvent>;
    /** The address of an issue or pull request, `<owner>/<repo>#<number>`. */
    to(target: GithubTarget): string;
};

Context ​

ts
function provideGithubContext(provider: IContextProvider, app: IGithubApp): void; // engine.provide under the key 'github'
function injectGithubContext(ctx: ToolContext): IGithubApp;                    // else ContextNotProvidedError

githubModule() provides its app; with a hand-built engine call provideGithubContext(engine, gh) after new Engine(). Inject in a tools factory (tools: (ctx) => injectGithubContext(ctx).readTools()), in a tool's execute or in an effect hook; see Context. One app per engine: a second provide throws InvalidAgentDefinitionError.

Module ​

ts
// @chamvi/github/module, needs @chamvi/app
function githubModule(options?: GithubModuleOptions): GithubModule; // name GITHUB_MODULE_NAME 'chamvi:github', .app: IGithubApp

Reads GITHUB_APP_ID, GITHUB_APP_PRIVATE_KEY, GITHUB_WEBHOOK_SECRET (comma-separated), GITHUB_INSTALLATION_ID, GITHUB_APP_SLUG and GITHUB_API_URL from options.env ?? process.env when it is called, unless options.app is given; explicit options win. setup contributes githubChannel() (options.channel, the approval link from CHAMVI_PUBLIC_URL unless channel.approvalUrl is given, the app's clock) to the app's channels, which the http module serves at /channels/<name>, and the engineCreated hook provides .app. @chamvi/app is an optional peer: the main entry never imports it. See Apps & Modules.

ts
/*
 * Copyright (c) 2026.
 * Author Peter Placzek (tada5hi)
 * For the full copyright and license information,
 * view the LICENSE file that was distributed with this source code.
 */

import type { Env } from '@chamvi/app';
import type { GithubAppOptions, IGithubApp } from '../app/types.ts';
import type { GithubChannelOptions } from '../channel/types.ts';

/** `githubChannel()` options; `approvalUrl` defaults to the UI link from `CHAMVI_PUBLIC_URL`, `clock` is the app's. */
export type GithubModuleChannelOptions = Omit<GithubChannelOptions, 'app' | 'clock'>;

export type GithubModuleOptions = Partial<GithubAppOptions> & {
    /** Used as is; no env is read then. */
    app?: IGithubApp;
    /** Default `process.env`, read when the factory is called. */
    env?: Env;
    /** The channel's options (name, mentions, approval link, timeout, body limit). */
    channel?: GithubModuleChannelOptions;
};
